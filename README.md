
# 🎮 NitroRogue

## 🚀 프로젝트 소개
> ![소개 이미지](images/title)
 
 Unity 엔진을 기반으로 제작된 멀티플레이 로그라이크 게임으로, 여러 플레이어가 협력하여 점차 강해지는 적을 상대하며 생존을 이어가는 전투 중심의 구조로 설계하였다. 전투를 통해 능력치를 강화하고 협동을 통해 더 높은 난이도의 적을 공략하도록 구성하였으며, 서버는 매치 관리, 몬스터 스폰과 경기 진행, 플레이어 동기화를 담당하고 클라이언트는 조작과 전투, UI 처리를 수행하여 안정적이고 몰입감 있는 멀티플레이 환경을 구현하였다.

## 💬 느낀 점

> * 김동환: 이번 프로젝트를 통해 Unity와 Mirror API를 활용한 Dedicated Server 방식의 멀티플레이 환경을 직접 구현하며 많은 것을 배웠습니다.
자료가 적어 어려움도 있었지만, 덕분에 네트워크 구조와 클라우드 서버 운영에 대한 이해를 크게 넓힐 수 있었습니다.
향후에는 서버 안정성과 기능을 보완하고, 친구 추가나 다양한 게임 모드 등 새로운 기능을 추가해 프로젝트를 발전시킬 계획입니다.

 * 이성민: 처음으로 네트워크 게임을 만들다 보니 시행착오도 많고 버그도 자주 발생했지만, 그만큼 네트워크 구조와 동작 방식에 대해 많이 배울 수 있었다. 앞으로 남은 반년 동안은 다양한 몬스터와 더 정교한 AI 시스템을 구현하는 것을 목표로 게임의 완성도를 높이도록 해야겠다.

* 김민준:Unity를 이용해 버추얼 및 3D 모델 제작 경험이 있었으나, 
새로운 구조의 작업을 진행하는 데 있어 많은 어려움을 겪었습니다. 하지만 이러한 경험을 통해 캐릭터와 네트워크 간의 통신에 대해 배울 수 있었습니다. 앞으로는 캐릭터의 전체적인 완성도를 높이고, 클라우드를 학습하여 게임 서버를 개선하는 것이 목표입니다.
 
* 황서진: Unity를 사용해서 맵을 제작하는 단계에서 처음 사용하는 툴이기에 익숙하지 않았고 많이 서툴렀기에 다음 학기에는 좀 더 다양한 기능을 사용하여 좋은 맵을 만들도록 하겠습니다.
