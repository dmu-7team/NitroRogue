## 🚀 프로젝트 소개

**NitroRogue**는 Unity 엔진을 기반으로 한 **멀티플레이 로그라이크 게임**입니다.  
플레이어들이 협력하여 점차 강해지는 적들을 물리치며 생존하는 **전투 중심 구조**로 설계되었습니다.

- **서버** 🖥️: 매치 관리, 몬스터 스폰, 경기 진행, 동기화 담당  
- **클라이언트** 🎮: 조작, 전투, UI, 사용자 입력 처리  

> 안정적이고 몰입감 있는 **실시간 멀티플레이 환경**을 제공합니다.

## 💬 팀원 소감

> 🧑‍💻 **김동환**  
> Unity와 Mirror API를 활용한 Dedicated Server 기반 멀티플레이 환경을 직접 구현하며  
> 네트워크 구조와 클라우드 서버 운영에 대한 이해를 넓혔습니다.  
> 향후에는 서버 안정성과 기능을 보완하고, 친구 시스템과 새로운 모드를 추가할 예정입니다.  

---

> 🎨 **이성민**  
> 네트워크 게임 제작은 처음이었지만, 시행착오를 통해 구조적 이해를 크게 향상시켰습니다.  
> 앞으로는 더 다양한 몬스터와 정교한 AI 시스템을 구현해 완성도를 높이겠습니다.  

---

> ⚙️ **김민준**  
> Unity로 3D 모델 제작 경험은 있었으나, 네트워크 통신 구조는 새로운 도전이었습니다.  
> 캐릭터와 서버 간 상호작용을 직접 구현하며 큰 배움을 얻었고,  
> 클라우드 학습을 통해 서버 품질을 개선할 계획입니다.  

---

> 🗺️ **황서진**
